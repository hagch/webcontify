# Content Entry Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Build the complete React/Next.js frontend for content entry management — dynamic forms, dynamic tables, detail pages with history, reference autocomplete.

**Architecture:** Feature-based folder structure in `src/features/content-entries/`. Field input registry (one component per type) + field column registry. Dynamic Zod schema builder generates form schema from `FieldDefinition[]`. React Query hooks generated by Orval from OpenAPI spec.

**Tech Stack:** Next.js 16, React 19, TypeScript, shadcn/ui, Tailwind v4, React Hook Form, Zod, next-intl, Orval, Vitest

---

## Context

Backend complete: 5 REST endpoints for content entries (list with cursor/filter/sort, detail, create, update, delete) + search + history in `content-api.yaml`.

**Key OpenAPI schemas:**
- `ContentEntryResponse` — `{ id, definitionId, values: Record<string, any>, createdAt, updatedAt, createdBy, updatedBy }`
- `ContentEntryPageResponse` — `{ items: ContentEntryResponse[], nextCursor?, hasNext }`
- `FieldDefinitionResponse` — `{ id, fieldKey, fieldType, required, unique, sortable, filterable, config, position }`
- `FieldType` — `TEXT | INTEGER | DECIMAL | BOOLEAN | DATE | ENUM | REFERENCE | MIRROR`
- `EntryReferenceResponse` — `{ id, display }` (for search/autocomplete)
- `EntryReferencePageResponse` — `{ items: EntryReferenceResponse[], nextCursor?, hasNext }`
- `EntryHistoryEventResponse` — `{ id, entryId, action: CREATED|UPDATED|DELETED, changedFields: Record<string, any>, changedAt, changedBy }`
- `EntryHistoryPageResponse` — `{ items: EntryHistoryEventResponse[], nextCursor?, hasNext }`

**Orval config:** `apps/platform/orval.config.ts` — `content` entry targets `../../openapi/content-api.yaml` → `./src/generated/content.ts`. Run `cd apps/platform && pnpm generate` to regenerate.

**Route pattern:** App uses `appId` (UUID) in existing workspace routes. The content entry routes will use `appSlug` + `defSlug` (matching the API path params).

**Existing patterns to follow:**
- Feature components: `apps/platform/src/features/apps/components/`
- Schemas: `apps/platform/src/features/apps/schemas/create-app.ts`
- i18n: `apps/platform/messages/en.json` + `de.json` (929 lines, `content.*` namespace exists)
- Tests mock `next-intl` via `vi.mock("next-intl", ...)` pattern from `features/content/components/__tests__/definition-node.test.tsx`
- Dialog pattern: `features/apps/components/create-app-dialog.tsx`
- Table pattern: `features/apps/components/app-table.tsx`
- Detail page pattern: `app/(workspace)/apps/[appId]/page.tsx` (tabs, breadcrumbs, AppHeader)

### Task 2: Dynamic Zod schema builder

**Goal:** Build the function that converts a `FieldDefinitionResponse[]` into a Zod schema for React Hook Form validation.

**File:** `apps/platform/src/features/content-entries/schemas/dynamic-entry-schema.ts`

```typescript
import { z } from "zod";
import type { FieldDefinitionResponse, TextFieldConfig, IntegerFieldConfig, DecimalFieldConfig, EnumFieldConfig } from "@/generated/content";

export function buildEntrySchema(fields: FieldDefinitionResponse[]): z.ZodObject<Record<string, z.ZodTypeAny>> {
  const shape: Record<string, z.ZodTypeAny> = {};

  for (const field of fields) {
    if (field.fieldType === "MIRROR") continue;

    const key = `cf_${field.fieldKey}`;
    let schema: z.ZodTypeAny;

    switch (field.fieldType) {
      case "TEXT": {
        const cfg = field.config as TextFieldConfig | undefined;
        let s = z.string();
        if (cfg?.minLength != null) s = s.min(cfg.minLength);
        if (cfg?.maxLength != null) s = s.max(cfg.maxLength);
        if (cfg?.pattern) s = s.regex(new RegExp(cfg.pattern));
        schema = s;
        break;
      }
      case "INTEGER": {
        const cfg = field.config as IntegerFieldConfig | undefined;
        let s = z.coerce.number().int();
        if (cfg?.min != null) s = s.min(cfg.min);
        if (cfg?.max != null) s = s.max(cfg.max);
        schema = s;
        break;
      }
      case "DECIMAL": {
        const cfg = field.config as DecimalFieldConfig | undefined;
        let s = z.coerce.number();
        if (cfg?.min != null) s = s.min(cfg.min);
        if (cfg?.max != null) s = s.max(cfg.max);
        schema = s;
        break;
      }
      case "BOOLEAN": {
        schema = z.boolean();
        break;
      }
      case "DATE": {
        schema = z.string().min(1, "Invalid date");
        break;
      }
      case "ENUM": {
        const cfg = field.config as EnumFieldConfig | undefined;
        const values = cfg?.allowedValues ?? [];
        if (values.length === 0) {
          schema = z.string();
        } else {
          schema = z.enum(values as [string, ...string[]]);
        }
        break;
      }
      case "REFERENCE": {
        schema = z.string().uuid();
        break;
      }
      default: {
        schema = z.unknown();
      }
    }

    if (!field.required) {
      schema = schema.optional();
    }

    shape[key] = schema;
  }

  return z.object(shape);
}

export type DynamicEntryFormValues = Record<string, unknown>;
```

```typescript
describe("buildEntrySchema", () => {
  it("skips MIRROR fields", () => {

  });

  it("coerces string input for INTEGER", () => {
    const schema = buildEntrySchema([makeField({ fieldKey: "count", fieldType: "INTEGER", required: true })]);

  it("builds DECIMAL field", () => {
    const schema = buildEntrySchema([

    expect(schema.safeParse({ cf_price: -1 }).success).toBe(false);
  });

  it("builds BOOLEAN field", () => {
    const schema = buildEntrySchema([makeField({ fieldKey: "active", fieldType: "BOOLEAN", required: true })]);
    expect(schema.safeParse({ cf_active: true }).success).toBe(true);
    expect(schema.safeParse({ cf_active: false }).success).toBe(true);
  });

  it("builds ENUM field with allowed values", () => {
    const schema = buildEntrySchema([

    const schema = buildEntrySchema([makeField({ fieldKey: "author", fieldType: "REFERENCE", required: true })]);

  it("applies .optional() for non-required fields", () => {
    const schema = buildEntrySchema([makeField({ fieldKey: "note", fieldType: "TEXT", required: false })]);

    expect(schema.safeParse({ cf_note: undefined }).success).toBe(true);
  });

    const schema = buildEntrySchema([makeField({ fieldKey: "name", fieldType: "TEXT", required: true })]);
    expect("cf_name" in schema.shape).toBe(true);
    expect("name" in schema.shape).toBe(false);
  });
});
```

```typescript
  type ContentDefinitionResponse,
} from "@/generated/content";
import { buildEntrySchema, type DynamicEntryFormValues } from "../../schemas/dynamic-entry-schema";
import { DynamicFieldRenderer } from "./dynamic-field-renderer";

type Mode = "create" | "edit";

interface EntryFormDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  mode: Mode;
  appSlug: string;
  defSlug: string;
  definition: ContentDefinitionResponse;
  entry?: ContentEntryResponse;
  allDefinitions?: ContentDefinitionResponse[];
}

export function EntryFormDialog({
  open,
  onOpenChange,
  mode,
  appSlug,
  defSlug,
  definition,
  entry,
  allDefinitions = [],
}: EntryFormDialogProps) {
  const t = useTranslations("entries.form");
  const queryClient = useQueryClient();
  const createEntry = useCreateContentEntry();
  const updateEntry = useUpdateContentEntry();

  const fields = (definition.fields ?? []).filter((f) => f.fieldType !== "MIRROR");
  const schema = buildEntrySchema(fields);

  // Build defaultValues from existing entry or empty
  function getDefaultValues(): DynamicEntryFormValues {
    if (mode === "edit" && entry?.values) {
      return Object.fromEntries(
        fields.map((f) => {
          const rawValue = (entry.values as Record<string, unknown>)[`cf_${f.fieldKey}`];
          // REFERENCE fields may come as EntryReference {id, display} — extract id
          if (f.fieldType === "REFERENCE" && rawValue && typeof rawValue === "object" && "id" in rawValue) {
            return [`cf_${f.fieldKey}`, (rawValue as { id: string }).id];
          }
          return [`cf_${f.fieldKey}`, rawValue ?? undefined];
        })
      );
    }
    return Object.fromEntries(fields.map((f) => [`cf_${f.fieldKey}`, undefined]));
  }

  const form = useForm<DynamicEntryFormValues>({
    resolver: zodResolver(schema),
    defaultValues: getDefaultValues(),
  });

  useEffect(() => {
    if (open) {
      form.reset(getDefaultValues());
    }
  }, [open, entry]);

  async function onSubmit(values: DynamicEntryFormValues) {
    const payload = { values };
    try {
      if (mode === "create") {
        await createEntry.mutateAsync({ appSlug, defSlug, data: payload });
        toast.success(t("createSuccess"));
      } else if (entry) {
        await updateEntry.mutateAsync({ appSlug, defSlug, entryId: entry.id, data: payload });
        toast.success(t("editSuccess"));
      }
      queryClient.invalidateQueries({ queryKey: getListContentEntriesQueryKey(appSlug, defSlug) });
      onOpenChange(false);
    } catch (err) {
      const error = err as { data?: { violations?: { field: string; message: string }[] } };
      if (error.data?.violations) {
        for (const v of error.data.violations) {
          form.setError(v.field as any, { message: v.message });
        }
      } else {
        toast.error(mode === "create" ? t("createError") : t("editError"));
      }
    }
  }

  const isPending = createEntry.isPending || updateEntry.isPending;

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent className="max-h-[90vh] overflow-y-auto sm:max-w-[560px]">
        <DialogHeader>
          <DialogTitle>{t(`title.${mode}`)}</DialogTitle>
        </DialogHeader>
        <Form {...form}>
          <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-4">
            {fields
              .sort((a, b) => a.position - b.position)
              .map((f) => (
                <DynamicFieldRenderer
                  key={f.id}
                  field={f}
                  control={form.control}
                  appSlug={appSlug}
                  defSlug={defSlug}
                  allDefinitions={allDefinitions}
                />
              ))}
            <DialogFooter>
              <Button type="button" variant="outline" onClick={() => onOpenChange(false)} disabled={isPending}>
                {t("cancel")}
              </Button>
              <Button type="submit" disabled={isPending}>
                {isPending && <Loader2 className="mr-2 size-4 animate-spin" />}
                {t(`submit.${mode}`)}
              </Button>
            </DialogFooter>
          </form>
        </Form>
      </DialogContent>
    </Dialog>
  );
}
```

```typescript
"use client";
import { useState, useCallback } from "react";
import { ArrowUp, ArrowDown, ArrowUpDown, X } from "lucide-react";
import { useTranslations } from "next-intl";
import Link from "next/link";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from "@/components/ui/table";
import type { ContentEntryResponse, FieldDefinitionResponse, ContentDefinitionResponse } from "@/generated/content";
import { FieldCellRenderer } from "./entry-table-columns";
import { EntryTableSkeleton } from "./entry-table-skeleton";

type SortDir = "asc" | "desc";

interface SortState {
  fieldKey: string;
  direction: SortDir;
}

interface EntryTableProps {
  definition: ContentDefinitionResponse;
  entries: ContentEntryResponse[];
  isLoading: boolean;
  isRefetching: boolean;
  hasNext: boolean;
  onLoadMore: () => void;
  onSortChange: (sorts: SortState[]) => void;
  onFilterChange: (filters: Record<string, string>) => void;
  appSlug: string;
  defSlug: string;
}

export function EntryTable({
  definition,
  entries,
  isLoading,
  isRefetching,
  hasNext,
  onLoadMore,
  onSortChange,
  onFilterChange,
  appSlug,
  defSlug,
}: EntryTableProps) {
  const t = useTranslations("entries");
  const [sorts, setSorts] = useState<SortState[]>([]);
  const [filters, setFilters] = useState<Record<string, string>>({});

  const fields = (definition.fields ?? []).sort((a, b) => a.position - b.position);

  function toggleSort(fieldKey: string) {
    setSorts((prev) => {
      const existing = prev.find((s) => s.fieldKey === fieldKey);
      let next: SortState[];
      if (!existing) {
        next = [...prev, { fieldKey, direction: "asc" }].slice(-3); // max 3
      } else if (existing.direction === "asc") {
        next = prev.map((s) => s.fieldKey === fieldKey ? { ...s, direction: "desc" as SortDir } : s);
      } else {
        next = prev.filter((s) => s.fieldKey !== fieldKey);
      }
      onSortChange(next);
      return next;
    });
  }

  function setFilter(fieldKey: string, value: string) {
    setFilters((prev) => {
      const next = { ...prev };
      if (value) {
        next[fieldKey] = value;
      } else {
        delete next[fieldKey];
      }
      onFilterChange(next);
      return next;
    });
  }

  function getSortIcon(fieldKey: string) {
    const s = sorts.find((x) => x.fieldKey === fieldKey);
    if (!s) return <ArrowUpDown className="size-3 opacity-50" />;
    return s.direction === "asc" ? <ArrowUp className="size-3" /> : <ArrowDown className="size-3" />;
  }

  if (isLoading) {
    return <EntryTableSkeleton columns={fields.length + 1} />;
  }

  if (entries.length === 0 && !isRefetching) {
    return (
      <div data-testid="entry-empty-state" className="flex flex-col items-center justify-center rounded-lg border border-dashed p-12 text-center">
        <p className="text-lg font-medium">{t("list.empty")}</p>
        <p className="mt-1 text-sm text-muted-foreground">{t("list.emptyDescription")}</p>
      </div>
    );
  }

  return (
    <div className="space-y-2">
      <div className="relative">
        {isRefetching && (
          <div className="absolute inset-0 z-10 flex items-center justify-center rounded-lg bg-background/60">
            <div className="h-6 w-6 animate-spin rounded-full border-2 border-primary border-t-transparent" />
          </div>
        )}
        <Table data-testid="entry-table">
          <TableHeader>
            <TableRow>
              {fields.map((field) => (
                <TableHead key={field.id} className="min-w-[120px]">
                  <div className="space-y-1">
                    <div className="flex items-center gap-1">
                      <span className="text-xs font-mono">{field.fieldKey}</span>
                      {field.sortable && (
                        <button
                          type="button"
                          aria-label={t("sort.asc")}
                          onClick={() => toggleSort(field.fieldKey)}
                          className="rounded p-0.5 hover:bg-accent"
                        >
                          {getSortIcon(field.fieldKey)}
                        </button>
                      )}
                    </div>
                    {field.filterable && (
                      <div className="flex items-center gap-1">
                        <Input
                          className="h-6 text-xs"
                          placeholder={t("filter.placeholder")}
                          value={filters[field.fieldKey] ?? ""}
                          onChange={(e) => setFilter(field.fieldKey, e.target.value)}
                        />
```

```typescript
function actionVariant(action: string): "default" | "secondary" | "destructive" {
  switch (action) {
    case "CREATED": return "default";
    case "UPDATED": return "secondary";
    case "DELETED": return "destructive";
    default: return "secondary";
  }
}

function FieldDiff({ fieldKey, diff }: { fieldKey: string; diff: Record<string, unknown> }) {
  const t = useTranslations("entries.history");
  const oldVal = diff.old;
  const newVal = diff.new;
  if (oldVal == null) return <div className="text-xs text-muted-foreground">{t("fieldAdded", { field: fieldKey, new: String(newVal ?? "") })}</div>;
  if (newVal == null) return <div className="text-xs text-muted-foreground">{t("fieldRemoved", { field: fieldKey, old: String(oldVal) })}</div>;
  return <div className="text-xs text-muted-foreground">{t("fieldChanged", { field: fieldKey, old: String(oldVal), new: String(newVal) })}</div>;
}

export function EntryHistoryList({ appSlug, defSlug, entryId, definition }: EntryHistoryListProps) {
  const t = useTranslations("entries.history");

    appSlug,
    defSlug,
    entryId,
    { size: 10, cursor },
    {
      query: {
        onSuccess: (res) => {
          const page = res.data;
          if (page && "items" in page) {
            if (!cursor) {
              setEvents(page.items ?? []);
            } else {
              setEvents((prev) => [...prev, ...(page.items ?? [])]);
            }
          }
        },
      },
    }
  );

  const page = data?.data;
  const hasNext = page?.hasNext ?? false;

  if (isLoading && events.length === 0) {
    return <div className="space-y-3">{Array.from({ length: 3 }).map((_, i) => <Skeleton key={i} className="h-16 w-full" />)}</div>;
  }

  if (events.length === 0) {
    return <p className="text-sm text-muted-foreground py-4 text-center">{t("empty")}</p>;

      {events.map((event) => (
```

```typescript
import { useState } from "react";
import { Loader2 } from "lucide-react";
import { toast } from "sonner";
import { useTranslations } from "next-intl";
import {
  Dialog, DialogContent, DialogDescription, DialogFooter, DialogHeader, DialogTitle,
} from "@/components/ui/dialog";
import { Button } from "@/components/ui/button";
import { useDeleteContentEntry } from "@/generated/content";

interface EntryDeleteDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
  appSlug: string;
  defSlug: string;
  entryId: string;
  onDeleted: () => void;
}

export function EntryDeleteDialog({
  open,
  onOpenChange,
  appSlug,
  defSlug,
  entryId,
  onDeleted,
}: EntryDeleteDialogProps) {
  const t = useTranslations("entries.delete");
  const deleteEntry = useDeleteContentEntry();
  const [restrictedMessage, setRestrictedMessage] = useState<string | undefined>(undefined);

  async function handleDelete() {
    setRestrictedMessage(undefined);

      await deleteEntry.mutateAsync({ appSlug, defSlug, entryId });
      toast.success(t("success"));
      onOpenChange(false);
      onDeleted();

      const error = err as { status?: number; data?: { detail?: string; violations?: unknown[] } };
      if (error.status === 409) {
        // RESTRICT violation — entry is referenced elsewhere
        setRestrictedMessage(t("restricted", { count: 1 }));
      } else {
        toast.error(t("error"));
        onOpenChange(false);
      }
    }

          <DialogTitle>{t("title")}</DialogTitle>
          <DialogDescription>
            {restrictedMessage ?? t("description")}
          </DialogDescription>
        </DialogHeader>
        <DialogFooter>
          <Button
            variant="outline"
            onClick={() => onOpenChange(false)}
            disabled={deleteEntry.isPending}
          >
            {t("cancel")}
          </Button>
          {!restrictedMessage && (
            <Button
              variant="destructive"
              onClick={handleDelete}
              disabled={deleteEntry.isPending}
            >
              {deleteEntry.isPending && <Loader2 className="mr-2 size-4 animate-spin" />}
```

## Common Gotchas

1. **`values` is `Record<string, any>`** — the backend serializes `Map<String, Object>` as flat JSON. All field keys are prefixed `cf_` in the map. Cast carefully; do not assume strong typing.

2. **REFERENCE values come back as `EntryReference` objects `{id, display}`** — not raw UUIDs. The form must extract `.id` when pre-filling edit forms (see `getDefaultValues` in `entry-form-dialog.tsx`).

3. **MIRROR fields are read-only** — skip them in `buildEntrySchema`, `DynamicFieldRenderer`. Render them in detail/table views as badge with count.

4. **Cursor is opaque** — just pass `page.nextCursor` directly. Never decode or modify it.

5. **Sort params URL form** — the `useListContentEntries` hook takes `sort` as `string[]` e.g. `["cf_title,asc", "cf_created_at,desc"]`. Build this array from sort state.

6. **Filter params** — the API accepts RHS operator syntax: `?cf_title=eq:Hello`. Build these as extra query params via the params object spread. Verify how Orval maps the `listContentEntries` params — check the generated hook signature in `src/generated/content.ts` after regeneration.

7. **`onSuccess` callback in React Query v5** — if the project uses TanStack Query v5, `onSuccess` moved to `mutateAsync().then()`. Check the existing codebase patterns (e.g., `app-table.tsx`, `create-app-dialog.tsx`) to confirm which React Query version is in use and follow the same pattern.

8. **`targetDefSlug` for REFERENCE search** — the `useSearchContentEntries` endpoint takes `defSlug` (the target definition's slug), not the source definition's slug. The `ReferenceFieldInput` component resolves this via `_targetDefSlug` injected by `DynamicFieldRenderer` using `allDefinitions`. The entry list page must pass `allDefinitions` from a `useListContentDefinitions(appSlug)` call.

9. **Route conflict** — `[appSlug]` and `[appId]` are separate route groups. The existing `/apps/[appId]` uses UUID; the new `/apps/[appSlug]/content/[defSlug]/entries` uses slug. These do NOT conflict in Next.js because they are different route segments. However, if both match the same pattern, add a type guard or use route groups.

10. **`getListContentEntriesQueryKey` name** — verify the exact query key function name generated by Orval after regeneration. It may differ (e.g. `getListContentEntriesQueryKey` vs `listContentEntriesQueryKey`). Always grep the generated file after running `pnpm generate`.
